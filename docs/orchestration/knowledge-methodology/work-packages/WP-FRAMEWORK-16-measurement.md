## 3. Критерии приёмки

1. Таблица сырых метрик, журналы, оценка вариативности, причинные ограничения; реальные кейсы отдельно от replay.
2. Все подобласти покрыты либо явно исключены с причиной; выводы привязаны к проверяемым источникам.
3. По механизму описаны задача, потребитель, цена, предотвращаемый дефект, простая альтернатива и риск её применения.
4. Отделены факты, измерения, выводы и гипотезы; отсутствующее evidence не заменено уверенностью.
5. Для каждого кандидата дана категория KEEP / SIMPLIFY / MERGE / DELETE / HARNESS / DEFER с условиями применимости; отсутствие кандидатов допустимо при обосновании.
6. Выполнены проверки артефакта из протокола. Исходники NaCl не изменены; экспериментальные изменения family-cinema перечислены, исходное состояние графа восстановлено/сверено. Приложены ограничения и вопросы для следующей программы.

## 4. Порядок сдачи

Исследователь возвращает структурированный отчёт и ссылки на evidence координатору. Координатор проверяет выводы и сохраняет `reports/WP-FRAMEWORK-16.md`; подтверждает критерии до смены статуса. Допустимы REVISE и ACCEPTED; DONE означает принятие исследования, без фиктивных стадий MERGED/PROD. Rollback: отозвать неподтверждённый вывод отдельной записью, сохранить историю, пересдать отчёт; исходники NaCl не меняются; для family-cinema восстановить экспериментальный baseline согласно spec/family-cinema-testbed.md.
