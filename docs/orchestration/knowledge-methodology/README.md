# Актуализация знаний и упрощение методологии

Программа `knowledge-methodology` по концепции единого оркестратора (pepper-orchestrator).
Создана 2026-11-02. Тег в сообщениях и заголовках PR: `[KNOWLEDGE]`.

## С чего начать

1. [Итоговая сдача WP-18](reports/WP-FRAMEWORK-18.md) — карта комплекта и его ограничения.
2. [Аудит устройства NaCl](reports/final-audit.md) — цепочки BA, SA, TL, graph и платформы; польза механизмов и границы доказательств.
3. [Целевая методология](reports/target-methodology.md) — предлагаемый процесс с сохранением graph как основы знаний.
4. [Проект программы модернизации](reports/implementation-handoff.md) — M0–M5, проверки, миграция и откат.
5. [Девять исторических ситуаций](reports/WP-FRAMEWORK-19.md), [проверки прототипов](reports/WP-FRAMEWORK-16.md) и [независимая оценка комплекта](reports/WP-18-independent-review.md). [Сохранённые исторические тесты и логи FR-014](reports/evidence/fr014-historical/README.md) — черновые материалы, открытые для чтения.
6. [Урегулирование WP-02–16](reports/WP-02-16-disposition.md) — по каждому пакету сохранённые отчёты, независимый verdict PARTIAL и конкретные невыполненные критерии.

**Граница результата:** WP-02–16 закрыты как `CANCELLED (PARTIAL сохранён; остаток отложен, D-16)` — полный исходный объём не выполнен. Результаты и двухраундовые verdicts сохранены, оставшиеся требования направлены в предполагаемые задачи будущей программы. Реальная экономия, полная безопасность внедрения и часть поведения graph/клиентов не доказаны. Исследование не изменяет исходники NaCl и не является выпуском модернизации.

## Правила в одном абзаце

Пишет сюда только координатор. По D-2 программа исследовательская: исходники NaCl и установленные скиллы остаются без изменений. Исследователи читают области и сдают evidence; координатор проверяет и сохраняет отчёты. D-1 не расширяет этот объём: delivery на hold. Реализация рекомендаций — другая программа.

План и решения: [PLAN.md](PLAN.md), [decisions.md](decisions.md), [протокол](spec/research-protocol.md). Текущее состояние и историю сверять по [status.md](status.md); ограниченные результаты не подменяют невыполненные исходные критерии.
