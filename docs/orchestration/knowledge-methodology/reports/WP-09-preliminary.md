# WP-09: предварительное исследование графа и синхронизации

[Legacy node и project lease](WP-09-null-project-lease-trace.md) — source-level трасса; runtime UNKNOWN.

Предисследование до принятия WP-01, SHA NaCl `20fe4c6a56482e85d3ea9a9ebaadb37206047e41`. Ни graph/network write, ни восстановление, ни конкурентные пробы не выполнены. Цена и частота unknown; категории DEFER.

1. **Источники истины.** `nacl-tl-core/references/remote-mode-coordination.md:3–19,50–61` определяет graph как источник remote Task/Wave, `.tl/status.json` как cache. `nacl-ba-sync/SKILL.md:11–17,56–60,89–128` различает визуальную board и структурный graph. Успешная graph запись до падения board сохранения — отдельный crash/replay case; нельзя считать cross-store транзакцию доказанной. `nacl-tl-full/SKILL.md:912–951` описывает graph→JSON и recovery, но сам текст не реализует совместную транзакцию двух хранилищ; forensic запись не равна продвижению фазы.
2. **Идентичность и конкурентность.** Legacy `nacl-core/scripts/resolve-developer-id.mjs:4–16,60–65` строит ID из конфигурации/env или email+machine, а `claim-task.mjs:24–42` допускает re-claim тем же ID. Два процесса с одинаковым default ID могут не различаться legacy claim; live конфликт не проверен. Это не project mutex и не аутентификация.
3. **Разные границы.** Full local gateway `graph-gateway/principal.mjs:30–68`, `identity.mjs:88–146`, `concurrency-cypher.mjs:136–165,279–295` задаёт OS principal, worker digest, RBAC, fencing, CAS и idempotency. Digest сам по себе не аутентификация отдельной агентской сессии под одним OS uid. Public HTTP `services/nacl-mcp/README.md:3–16,27–45` описывает внешний OAuth verifier и allowlisted operations; работающий deployment не проверен. Skills-only использует project-local MCP; его гарантии нельзя приравнять к gateway без probe.
4. **Backup.** `graph-infra/scripts/handover-export.sh:49–56,62–97`, `handover-import.sh:80–101,106–145` — полный export/import и counts, с рисками, описанными в [graph baseline](WP-01-graph-baseline-risks.md). `codex-plugin-src/package/runtime/graph-cli/backup-contract.mjs:28–52,63–74` содержит schema и representative query digests; это не доказательство полной семантической равнозначности или совместимости с Family Cinema MCP.
5. **Analyst Tool.** `analyst-tool/server/src/routes/skills.ts:44–49,110–143` отдаёт runId до завершения и при пустом/недоступном графе может использовать filesystem fallback. Для regenerate all `services/renderable.ts:85–108,117–122,209–215` при поздней ошибке возвращает уже накопленный список без partial/error; route :110–139 ставит batch только из него и сообщает source=graph, не проверяя полноту. При пустом discovery файловый fallback без eligible boards может вернуть сообщение о пустом графе и директории даже после ошибки или фильтрации. Это source-only, enqueue не равен completion; listBoards и иные ошибки могут дать другой исход. Предлагаемые controls — отказ первого/последующего query, реально пустой граф и неподдерживаемые local boards. Нужно различать empty и network error, проверить graph read-back и статус при ошибке сохранения board/hash. Синхронизация не доказана самим exit 0/runId.

Гипотеза для малого проекта: versioned Markdown + atomic Git commit + проверки ID/ссылок. Цена — возможная утрата живых traversal, транзакционных concurrent edits и cross-project impact; для нескольких writers нужно отдельно доказать identity, fence/CAS, recovery и evidence. Размер файлов не измеряет ценность/стоимость. WP-16 должен сравнить на одинаковых сценариях, WP-17 — проверить отрицательные случаи.
