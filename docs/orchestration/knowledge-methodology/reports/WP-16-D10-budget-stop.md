# D-10: остановка по наблюдению локальных счётчиков

Владелец согласовал отдельный лимит D-10 на оставшуюся подготовку одной A/B-пары, запуск и независимое review; решение записано 2026-11-03 09:55Z. Координатор запустил двух read-only исследователей для готовности стенда и учёта до подтверждения способа общего контроля. Это была ошибка порядка: требовалось сначала убедиться в возможности контролировать бюджет всех участников.

2026-11-03 09:56Z исследователь учёта сообщил, что счётчик одной дочерней сессии уже превысил 1 200 000 input. Координатор остановил незавершённого исследователя и приостановил watcher; A/B не запускался.

Координатор read-only прочитал только последние события `event_msg/token_count` в двух локальных JSONL-сессиях от 2026-11-03 (без вывода сообщений или account-wide данных):

| Session ID | UTC события | total input | cached input (внутри input) | output |
|---|---|---:|---:|---:|
| `01a1a0d5-d89f-77f1-8f11-7e01600cd814` | 09:56:19.746Z | 1 763 541 | 1 740 416 | 1 856 |
| `01a1a0d5-ec98-7843-9ed6-88a3cd5c0771` | 09:56:22.330Z | 1 332 139 | 1 318 656 | 1 729 |

Это последние накопительные значения отдельных сессий, не набор величин для сложения последовательных снимков; cached input уже включён в input. Семантика счётчика, перекрытия с родителем, фактическая тарификация и полный multi-thread расход не установлены. Каждое отдельное значение превышает согласованные 1,2M input в консервативном прочтении. Нельзя ни гарантировать остаток D-10, ни объявлять эти числа счётом к оплате. Продолжать расход по D-10 и запускать A/B нельзя до разрешения учёта и нового решения владельца; в рабочей области сохранены только метаданные, текст переписки и секреты не копировались.

Read-only preflight также выявил: draft oracle не покрывает все AC, техническая blind isolation не доказана, historical graph baseline/reset не подтверждён. Это отдельные незакрытые условия. Исходники NaCl и live graph не изменялись.
