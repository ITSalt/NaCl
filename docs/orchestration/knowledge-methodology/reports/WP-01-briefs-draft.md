# WP-01: черновики одинаковых brief и acceptance-критериев

Для одинаковой выдачи вариантам A/B. Это переработанные исследовательские задания, а не дословные исторические документы. До запуска нужно подтвердить все неподтверждённые детали и включить все обязательные требования в оба входа; скрытый harness не должен добавлять неоговорённые требования. Критерии не заморожены и полная приёмка не проводилась; позднее для FR-014 выполнены отдельные предварительные проверки среды и synthetic controls, см. WP-16 evidence.

Для FR-014 исторический baseline использует npm и отдельные lockfiles, FR-029 npm workspaces, более поздние кандидаты pnpm. Совместимость, изоляция refs/истории, graph snapshot и независимый harness ещё не проверены; это черновик, корпус не заморожен.
