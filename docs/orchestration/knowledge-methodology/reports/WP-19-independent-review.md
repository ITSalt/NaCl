Больше сбора по случаям не выполнялось; независимая приёмка и две правки текста по её замечаниям не являются дополнительной волной сбора. Для истории: registry фиксирует формальный сбор как первый раунд, поэтому он сам по себе не отражает предварительный сбор; лимит владельца учтён по фактическим действиям.
