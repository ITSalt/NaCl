Частота, число чтений/запусков/подтверждений, стоимость и фактический эффект UNKNOWN; требование confirmation в Codex — текст, не измеренное число. Риск по замыслу: ложный диагноз, потеря источника и действие по устаревшему report. Историческая причинность не доказана. Альтернатива: versioned scope/date/SHA-bound diagnostic ledger с per-dimension provenance и freshness gate; риск утраты remote/local semantics, неполных данных и acknowledgment.

Предлагаемые negative: недоступный runner без фиктивного composite; partial collector; report старше fix; remote status mismatch без stale graph; non-PASS без acknowledgment; недоступный graph не считать отсутствием stale nodes. Positive: доступные version-bound источники, актуальный report и отдельно подтверждённый reconcile с read-back. Ни один сценарий не выполнялся. До смены DEFER нужны независимая проверка producer→report→reconcile, обеих проекций, partial/stale/non-PASS и измерение стоимости.
