# FR-014: независимый черновик black-box проверок

Исследователь получил только краткий функциональный brief; историю Git, файлы проекта и реализацию не открывал по инструкции. Это design, а не исполняемый harness: hash тестов, реализуемость browser events и RED/GREEN ещё не проверены. Точные требования для A/B подлежат заморозке до прогона.

Данные: карточки завершённой фотографии с различимыми оригиналом/улучшением, отдельно uploading/enhancing; достаточно длинная страница; мышь с колесом, клавиатура и реальное или эмулированное мультитач-устройство. При наличии подтверждённого требования — отдельная карточка с одной версией.

1. Открыть завершённое фото и проверить выбранное изображение в полноэкранном просмотре; повторить для другой карточки.
2. Для uploading и enhancing независимо проверить отсутствие открытия.
3. Увеличивать/уменьшать колесом и pinch; проверить границы 1–3× и попытки выйти за них.
4. Крестик, фон и Escape проверить независимо с повторным открытием.
5. Переключить оригинал/улучшение туда и обратно, проверить правильную карточку; наличие одной версии проверять только при подтверждённом общем контракте.
6. Действия карточки выполняются по назначению и случайно не открывают просмотр.
7. При открытом просмотре фон не прокручивается ни колесом, ни касанием; после закрытия скролл восстанавливается.

До заморозки уточнить/задать одинаково обеим arm: точный набор кнопок и их ожидаемые действия; семантику клика на изображение/фон; отсутствие второй версии и первую выбранную версию; начальный масштаб и его сохранение; поддерживаемые браузеры/устройства; позицию прокрутки и keyboard focus; реакцию на изменение статуса обработки. Не проверять скрытые дополнительные продуктовые требования, которые не были сообщены обеим arm. Историческая спецификация и post-change tests могут подсказать решение и не должны автоматически становиться входом исполнителей.
