# Актуализация знаний и упрощение методологии — план

> Пишется один раз, правится редко. Текущее состояние — в `status.md`.

## Цель и условие завершения

Актуализировать знания NaCl и упростить методологию для пользователей Claude Code и Codex. Конкретные изменения определяются следующим этапом `plan` по фактам из текущего репозитория.

Условие завершения будет конкретизировано при планировании: согласованный объём реализован, проверки и приёмка подтверждены, обновления опубликованы и доступны пользователям. До определения проверяемых критериев программа не закрывается.

## Объём

1. Локальный репозиторий NaCl; один начальный модуль `framework` охватывает все пути.
2. Анализ актуальности знаний, правил и пользовательских сценариев методологии; изменения оформляются пакетами работ после планирования.
3. Проверка, push, merge и публикация обновлений оркестратором в рамках D-1.

### Не входит

- Изменения инфраструктуры, прав доступа и БД без отдельного разрешения владельца.
